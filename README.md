# Microsoft Security Envisioning Workshops

Repositorio de contenido y materiales para los 4 talleres oficiales de seguridad de Microsoft:

| Taller | Enfoque | Kit Office |
|--------|---------|:----------:|
| **Cloud Security** | Defender for Cloud, CSPM, multi-cloud | 11 archivos (00–10) |
| **Data Security** | Microsoft Purview, DLP, IRM v8.5.x | 24 archivos (DS-00 a DS-90) |
| **Modern SecOps** | Microsoft Sentinel, SIEM/SOAR | 11 archivos (00–13) |
| **Threat Protection** | Defender XDR, Entra ID, Zero Trust | 12 archivos (00–13) |

> ⚠️ **`README.md` es documentación humana.** El system prompt del agente AI está en [`SYSTEM_PROMPT.md`](SYSTEM_PROMPT.md). No modifiques este archivo para instrucciones del agente.
